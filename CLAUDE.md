# treaple

Репозиторий-хранилище навыков Claude Code. Кода приложения здесь нет — только
`.claude/skills/` и вспомогательные скрипты установки.

## Работа с видео

Шесть навыков покрывают монтаж. Выбор:

- **«нарезать длинное видео на рилсы», «шортсы из подкаста», «субтитры на видео»**
  → `reels-autocut`. Самодостаточен: ffmpeg + Python, движок не нужен.
- **«убрать паузы», «вырезать эээ и ну», «сделать динамичнее»** → `jumpcut`.
  Запускается до нарезки.
- **«обложки», «описания», «версия под ленту»** → `reels-publish-pack`. После нарезки.
- **«смонтируй ролик под ключ», «собери lesson»** → `reel-turnkey`.
- **«ролик без камеры», «анимационный рилс», «видео из озвучки»** → `motion-reel`.
- **«переделай чужой рилс», «разбери донора в карточки»** → `reel-from-donor`.

Последние три требуют движка AutoMontage-Agent
(`bash scripts/install-automontage-engine.sh`, затем `AUTOMONTAGE_HOME`).
Если движка нет, а задача — просто нарезка, не отправляй пользователя ставить
движок: `reels-autocut` решает её сам.

## Правила для навыков нарезки

- **Показывай план до рендера.** `plan.json` правится руками или тобой; рендер
  необратимо съедает минуты. Исключение — пользователь явно сказал «просто нарежь».
- **Не вываливай JSON в чат.** Таблица: id, тайминг, длина, первая фраза.
- **Проверяй первый клип** (`--only clip-01`) прежде чем ставить пачку из восьми.
- **Говори, что вышло хуже.** Где кадр обрезал лишнее, где субтитры спорные.
  Восемь файлов без комментария — не результат.

## При правке скриптов навыков

Скрипты в `.claude/skills/*/scripts/` — обычный Python без внешних зависимостей
в основном пути (стандартная библиотека + вызовы ffmpeg). numpy, opencv и
faster-whisper подключаются опционально, с рабочим запасным вариантом. Держи
это свойство: навык должен запускаться там, где стоит только ffmpeg и Python.

Проверка после правок:

```bash
python3 .claude/skills/reels-autocut/scripts/autocut.py --help
python3 .claude/skills/jumpcut/scripts/jumpcut.py --help
python3 .claude/skills/reels-publish-pack/scripts/publish_pack.py --help
```

Полная проверка требует ffmpeg и тестового видео — собери его через
`ffmpeg -f lavfi -i testsrc2=s=1280x720:d=40 -f lavfi -i sine=f=280:d=40 …`.
