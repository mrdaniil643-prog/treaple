# Демо для claude.ai

Сборка сайта в одну страницу без сервера: брони и билеты хранятся в браузере посетителя, деньги не списываются. Её можно открыть по ссылке, не запуская сервер.

```bash
python3 tools/claude-demo/build.py   # результат в tools/claude-demo/build/
```

Сборщик берёт текущие файлы из `public/` и `server/halls.js` и подменяет обращения к серверу на `src/js/backend.js`. После изменений сайта пересоберите и опубликуйте `build/index.html` вместе с папками `css`, `js`, `img`, `vendor`.

## Админка в демо

Ссылка «Админка» в оранжевой полосе, пароль `demo`. Работает всё, кроме контролёров: заказы, правка билетов и покупателя, «Впустить гостя», вход по коду или QR, возвраты, закрытие продажи, новые события, графики. Данные те же, что у гостя, и лежат в этом же браузере: админка видит только заказы, сделанные на этом устройстве. `confirm()` в просмотрщике claude.ai не работает, поэтому сборщик заменяет его на своё окно `ask()`.
