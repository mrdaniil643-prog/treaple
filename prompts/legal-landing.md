# Лендинг юриста — «Дело №»

## Роль и пайплайн скиллов

Ты — арт-директор и фронтенд-инженер одновременно. Работай строго в этом порядке,
не перескакивая:

1. `/frontend-design` — сначала сформулируй арт-дирекцию. Обоснуй выбор предметной
   областью (юриспруденция: документ, дело, инстанция, печать), а не модой.
   Запрещены дефолты, по которым сайт узнаётся как шаблон: Inter + фиолетовый
   градиент, «стеклянные» карточки, иконки-эмодзи, стоковые рукопожатия.
2. `/ui-ux-pro-max` — подбери палитру, пару шрифтов, шкалу отступов и типографики,
   состояния компонентов (default/hover/focus-visible/active/disabled/loading/error),
   проверь контраст по WCAG AA.
3. `/theme-factory` — зафиксируй итог как единый набор CSS-переменных (`--color-*`,
   `--font-*`, `--space-*`, `--radius-*`, `--ease-*`, `--dur-*`). Ни одного
   хардкод-цвета в разметке.
4. `/stop-slop` — весь текст на сайте пиши через этот скилл. Никаких «мы ценим
   каждого клиента», «команда профессионалов», «индивидуальный подход».
   Копирайт говорит фактами и цифрами.
5. Реализация.
6. `/webapp-testing` — Playwright: скриншоты 390 / 768 / 1440 px, прогон отправки
   формы, проверка консоли на ошибки. Приложи скриншоты к результату.

## Концепция

Метафора — **личное дело клиента**. Сайт выглядит как papka с документами, но
современная: тонкие линейки как на бланке, номера разделов моноширинным шрифтом
(`Дело №01`, `Дело №02`), золото используется как фольга — волосяная линия и
мелкая типографика, а не заливка кнопок целиком. Много воздуха, крупные
заголовки с засечками, текст без засечек, никакого декора «просто так».

Тональность: спокойная уверенность. Клиент приходит в панике — сайт должен
понижать пульс, а не повышать.

## Палитра (опорная, уточни через `/ui-ux-pro-max`)

- Фон: графит `#12151A` → глубокий синий `#0E1520`
- Текст: тёплый белый `#EDE9E3`, вторичный `#8D94A0`
- Акцент: бронза `#B8894A`, только линии, подчёркивания, цифры и один primary-CTA
- Никаких трёх акцентов. Один. Поверхности отличаются на 4–6% светлоты, не рамками.

## Секции

### 01 — Hero
Заголовок бьёт в боль клиента, а не в самопрезентацию: «Повестка, долг, раздел
имущества — разберём за один звонок». Подзаголовок снимает страх цены и
обязательств («Первая консультация 20 минут, бесплатно, без записи»).
Форма прямо в первом экране: имя + телефон + кнопка. Два поля, не больше.

Анимация: заголовок появляется построчно с маской (`clip-path`, не opacity
по буквам), под ним прочерчивается бронзовая линия слева направо. Фон —
медленный градиентный шум или очень редкие частицы, которые **замирают**, когда
пользователь начинает печатать в форме. Параллакс не больше 12 px.

### 02 — Проблемы клиента
4 карточки: развод и дети, наследство, суд, взыскание долгов. На каждой —
формулировка от первого лица клиента («Бывший не платит алименты три месяца»),
а ниже — что конкретно делает юрист. Иконки — линейные, одной толщиной штриха,
нарисованы как пометки на полях документа.

Анимация: карточки выходят каскадом со сдвигом 60 ms друг за другом;
на hover карточка не «прыгает», а поднимается на 4 px и подсвечивает бронзовую
линию слева — как выделенная строка в деле.

### 03 — Почему мы
Цифры: лет практики, выигранных дел, % дел, закрытых без суда, средний срок.
Счётчик отсчитывает как счётчик на табло — цифры прокручиваются вертикально, не
просто увеличиваются. Запуск по `IntersectionObserver`, один раз, порог 0.4.
Под каждой цифрой — короткая расшифровка мелким шрифтом, иначе цифра не верится.

### 04 — Как мы работаем
Таймлайн 4 шага: звонок → изучение документов → стратегия и договор → ведение
дела. Линия заполняется бронзой по мере скролла (`scroll-timeline` где есть
поддержка, иначе `IntersectionObserver` + CSS-переменная). Каждая точка
«защёлкивается» при активации. У шага — честный срок («в течение дня», «2–3 дня»).

### 05 — Отзывы
Слайдер с плавной сменой карточек, auto-play с паузой на hover и на focus,
свайп на тач, стрелки и точки доступны с клавиатуры. В отзыве — суть дела и
результат, а не «спасибо большое». Если есть — номер дела или суд, это добавляет
веса.

### 06 — О юристе
Портрет (ч/б или с приглушённой цветокоррекцией под палитру), статус в реестре,
номер удостоверения, специализация, публикации. Fade-in с лёгким подъёмом.
Рядом — факсимиле подписи, прорисовывающееся по SVG-пути.

### 07 — Основная форма
Поля: имя, телефон (маска +7), описание ситуации (textarea), согласие на
обработку ПДн (чекбокс, обязательный), honeypot-поле скрытое от людей.
Микроанимация фокуса: бронзовая линия поля вырастает от центра, лейбл
уезжает наверх. Валидация — на blur, а не на каждый символ.

Успех: **штамп** «Заявка принята» с лёгким поворотом и оттиском — метафора
предметной области вместо конфетти. Ниже — что будет дальше и за сколько
перезвонят.

### 08 — FAQ
Аккордеон на `<details>`/`<summary>` (доступность из коробки), высота
анимируется через `grid-template-rows: 0fr → 1fr`. Вопросы — те, что реально
гуглят: «Сколько стоит?», «Можно ли выиграть, если пропущен срок?»,
«Что если у второй стороны сильный юрист?».

### 09 — Футер
Контакты, карта (ленивая подгрузка iframe только по клику на заглушку —
иначе он убивает LCP), ИНН/ОГРН, ссылки на политику ПДн.

## Моушен — правила

- Длительность 300–450 ms, `cubic-bezier(0.22, 1, 0.36, 1)`.
- Анимируем только `transform` и `opacity`. Ни `top`, ни `height`, ни `box-shadow`
  в кадре.
- Каждый scroll-триггер срабатывает один раз. Секция не мигает при обратном скролле.
- Sticky-кнопка «Заказать звонок» появляется после ухода hero, прячется, когда
  основная форма в зоне видимости — иначе две одинаковые CTA конкурируют.
- `@media (prefers-reduced-motion: reduce)` — всё сводится к мгновенному
  появлению без сдвигов. Это обязательное требование, не опция.
- Никакого контента, который существует только внутри анимации: без JS страница
  читается полностью.

## Техника

- Стек: статический HTML + CSS + минимум ванильного JS, либо Next.js (static export) —
  выбери и обоснуй одной строкой. Без тяжёлых анимационных библиотек: Web
  Animations API и CSS достаточно.
- Адаптив mobile-first, тач-цели ≥ 44 px, без горизонтального скролла на 360 px.
- Форма отправляется в **Telegram-бот**: `POST` на serverless-функцию
  (`/api/lead`), которая дёргает `https://api.telegram.org/bot<TOKEN>/sendMessage`.
  Токен и `chat_id` — только в переменных окружения `TG_BOT_TOKEN`, `TG_CHAT_ID`,
  никогда в клиентском коде. Добавь rate-limit по IP и проверку honeypot.
  Резервный канал — дублирование на email через Resend, если задана `RESEND_KEY`.
- Шрифты — self-hosted `woff2`, `font-display: swap`, preload только для
  заголовочного начертания.
- Изображения — AVIF/WebP, явные `width`/`height`, `loading="lazy"` ниже первого экрана.

## Готово, когда

- Lighthouse mobile: Performance ≥ 90, Accessibility ≥ 95, CLS < 0.05, LCP < 2.0 s.
- Клавиатурная навигация проходит весь путь до отправки формы, фокус виден везде.
- Скриншоты 390 / 768 / 1440 приложены, консоль чистая.
- Ни одного текста, который мог бы стоять на сайте любого другого юриста.
