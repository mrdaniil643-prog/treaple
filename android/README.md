# Приложение на очки Rokid Glasses

APK, который ставится на сами очки: тап по тачпаду → вопрос голосом → ответ
озвучивается и выводится на HUD, код показывается отдельными страницами.

Очки работают на YodaOS — это Android 12 (API 31/32), поэтому приложение
обычное андроидное: системный `SpeechRecognizer` для распознавания,
`TextToSpeech` для озвучки, HTTP до моста из корня репозитория.

```
[очки] тап → ASR → POST /v1/chat/stream ──▶ [мост] ──▶ Claude
                    ◀── SSE: delta…done ──┘
             TTS + текст на HUD
```

## Почему через мост, а не напрямую в Anthropic API

Ключ Anthropic в APK — это ключ, который лежит на устройстве и вынимается из
пакета за минуту. Ключ остаётся на мосту, очки ходят к мосту по своему токену,
и его можно отозвать, не трогая ключ. Заодно мост держит историю диалога и
готовит текст под HUD — на очках это делать нечем.

## Сборка

Нужен Android SDK (platform 34, build-tools) и JDK 17.

```bash
cd android
gradle wrapper                      # один раз, если нет gradlew
./gradlew :app:assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

Через Android Studio: открыть папку `android/`, дождаться синка, Run.

## Установка на очки

**По кабелю (5-контактный дев-кабель):**

```bash
adb devices                          # очки должны появиться в списке
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

**По Wi-Fi:**

```bash
adb tcpip 5555
adb connect <ip-очков>:5555
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Если adb до очков не добивается, APK можно залить компаньон-приложением с
телефона (Rokid CXR-M умеет ставить APK по Wi-Fi Direct) или сторонним
сайдлоадером — сути это не меняет, пакет тот же.

## Настройка без клавиатуры

Клавиатуры на очках нет, поэтому адрес моста и токен передаются в extras запуска:

```bash
adb shell am start -n dev.treaple.rokidclaude/.MainActivity \
  -e bridgeUrl https://bridge.example.com \
  -e token "$WEBHOOK_SECRET" \
  -e lang ru-RU
```

Настройки сохраняются в SharedPreferences — дальше приложение запускается с
иконки. Проверить всё без голоса (полезно, когда очки лежат на столе):

```bash
adb shell am start -n dev.treaple.rokidclaude/.MainActivity \
  -e ask "как в Kotlin сделать дебаунс"
```

## Управление

| Действие | Что делает |
|---|---|
| Тап по тачпаду / DPAD_CENTER | начать или прервать вопрос |
| Свайп вперёд-назад / DPAD влево-вправо | листать страницы ответа |
| Назад | выйти из ответа в ожидание |

Коды клавиш у разных прошивок отличаются. Если жест не срабатывает, посмотрите
`adb shell getevent -l` и допишите код в `onKeyDown` — все клавиши разбираются
в одном `when` в `MainActivity.kt`.

## Что учтено в UI

- Дисплей монохромный зелёный micro-LED на правый глаз: фон чёрный, текст белый,
  цветом ничего не кодируется — на этом экране оттенок один.
- Крупный шрифт (28sp) и по три строки на экран: мост уже режет текст под ширину
  HUD и присылает готовые `chunks`.
- Код никогда не читается вслух — он уходит на отдельные страницы моноширинным
  шрифтом (18sp, по 8 строк).
- Пока модель отвечает, на экране идёт «хвост» потока: видно, что система жива.
- Экран не гаснет, системные панели спрятаны.

## Файлы

| Файл | Зачем |
|---|---|
| `MainActivity.kt` | экран, состояния, тачпад и клавиши |
| `BridgeClient.kt` | HTTP + разбор SSE (`delta` / `done` / `error`) |
| `Voice.kt` | `SpeechRecognizer` и `TextToSpeech` |
| `Pages.kt` | сборка страниц HUD из ответа моста |
| `Settings.kt` | адрес моста, токен, язык, id сессии |

## Тесты

```bash
./gradlew :app:testDebugUnitTest
```

Покрыта сборка страниц HUD (`HudTest`) — чистая логика без Android.

## Ограничения

- Приложение не собиралось в CI этого репозитория: в окружении, где оно писалось,
  не было Android SDK. Проверьте сборку локально перед выкаткой на очки.
- Распознавание и синтез — системные, качество и наличие русского голоса зависят
  от прошивки очков. Если движка нет, приложение честно скажет об этом в статусе,
  а вопросы можно слать через `-e ask`.
- Мост должен быть доступен очкам по сети. Для HTTP-адреса в отладке в манифесте
  включён `usesCleartextTraffic`; в проде используйте HTTPS.
