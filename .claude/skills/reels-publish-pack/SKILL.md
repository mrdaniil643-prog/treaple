# Пакет для публикации

Скрипт: `scripts/publish_pack.py`. Три команды: `cover`, `variant`, `pack`.

Клипы этот навык не режет — он берёт готовые и доводит до выкладки. Нарезка —
`reels-autocut`.

## Всё сразу по манифесту

```bash
cd .claude/skills/reels-publish-pack/scripts

python3 publish_pack.py pack \
  --clips ~/reels/lecture/clips/clips.json \
  --plan  ~/reels/lecture/plan.json \
  --outdir ~/reels/lecture/publish \
  --ratios 4:5,1:1 --theme dark --font "Montserrat"
```

На выходе в `--outdir`:

- `<clip>-cover.jpg` — обложка с заголовком;
- `<clip>-4x5.mp4`, `<clip>-1x1.mp4` — версии под площадки;
- `captions.md` — по разделу на клип: хук, расшифровка, пустые места под описание
  и хештеги;
- `publish.json` — манифест путей.

`--plan` необязателен, но с ним в `captions.md` попадают хук и расшифровка — без
них писать описания вслепую.

## Описания и хештеги пишешь ты

Скрипт оставляет в `captions.md` пустые блоки намеренно. Механически сгенерированные
описания и хештеги — мусор: они пересказывают ролик вместо того, чтобы объяснить,
зачем его смотреть. Заполняй сам, по расшифровке рядом.

Что работает в описании:

1. **Первая строка — не пересказ.** Зритель уже посмотрел. Дай то, чего в ролике
   не было: цифру, оговорку, следующий шаг.
2. **Один призыв, конкретный.** «Сохрани, чтобы не искать» лучше, чем «ставь лайк
   и подписывайся».
3. **3–7 хештегов по теме.** `#рекомендации`, `#втоп`, `#рек` не дают ничего;
   тематические — дают. Смешивай широкие (`#монтаж`) и узкие (`#ffmpeg`).
4. **Длина — до трёх строк.** Остальное площадка спрячет под «ещё».

Заполненный `captions.md` покажи пользователю целиком: это текст, который он будет
публиковать от своего имени, он должен его вычитать.

## Обложка отдельно

```bash
python3 publish_pack.py cover clip.mp4 --out cover.jpg \
        --title "Главная ошибка новичков" --theme punch --position bottom \
        --font "Montserrat" --wrap 16
```

Темы: `dark`, `light`, `punch`, `mint`. Позиция: `bottom` (по умолчанию),
`center`, `top`. `--wrap` — символов в строке; для длинных заголовков уменьшай,
иначе плашка займёт пол-кадра. `--at 12.5` возьмёт конкретную секунду.

На вход принимается и видео, и картинка. Если рядом лежит JPG от `reels-autocut` —
бери его: в нём нет вшитых субтитров, и заголовок не ляжет поверх текста.
Команда `pack` делает это сама.

**Заголовок на обложке — не название файла.** Три-пять слов, обещание или вопрос.
«Как я сократил монтаж вдвое» работает, «Клип 3 из лекции» — нет.

## Версии под площадки

```bash
python3 publish_pack.py variant clip.mp4 --out clip-4x5.mp4 --ratio 4:5 --fit blur
```

Форматы: `9:16`, `4:5`, `1:1`, `16:9`. Вписывание: `blur` (размытый фон из того же
кадра, по умолчанию), `crop` (обрезать), `pad` (чёрные поля).

Из вертикального мастера в `4:5` и `1:1` режется верх и низ — **субтитры могут
уехать за край**. Проверь первый файл глазами. Если уехали — пересобери клип в
нужном формате с нуля через `reels-autocut render --ratio 4:5`, там субтитры
верстаются под конечный кадр.

`16:9` из вертикали — всегда `blur` или `pad`: кропом от кадра ничего не останется.

## Порядок

```
reels-autocut → (проверить клипы) → reels-publish-pack → вычитать captions.md → выкладка
```

Не запускай `pack` на непроверенных клипах: пересобирать пакет из восьми роликов
дороже, чем посмотреть их один раз.
