# Что ломается и что с этим делать

## `Не найден ffmpeg`

```bash
brew install ffmpeg                  # macOS
winget install Gyan.FFmpeg           # Windows
sudo apt install ffmpeg              # Debian/Ubuntu
```

Если ffmpeg стоит, но не в PATH: `export AUTOCUT_FFMPEG_DIR=/путь/к/bin`.

## `Не установлен faster-whisper`

```bash
python3 -m pip install faster-whisper
```

Первый запуск скачивает модель (`small` ≈ 500 МБ) — это одноразово. Если ставить
нечего или некогда, возьми готовые субтитры: `transcribe --import subs.srt`.
Выгрузку даёт YouTube, любой сервис расшифровки и большинство монтажек.

## Распознавание идёт очень долго

`--model tiny` для черновика; `--compute-type int8` ускоряет на CPU в разы;
`--no-vad`, если VAD режет тихую речь. Нормальная скорость на CPU для `small` —
примерно 3–6× реального времени, то есть час записи ≈ 10–20 минут.

## `Ни одного куска длиной N–M с.`

У говорящего короткие реплики или паузы не там, где ждёт скрипт.
Ослабь границы: `--min 10 --max 40`. Или увеличь `--pause-break 0.8`, чтобы
предложения склеивались охотнее.

## Клипы лезут друг на друга / все из одного места

`--spread 0.08` требует растащить их по таймлайну. Если после этого клипов
меньше, чем `--count`, — второй проход всё равно доберёт лучшие, но уже без
требования равномерности.

## Кадр едет не за тем объектом

`detector: "motion"` в `clips.json` значит, что лиц не нашлось и кроп поехал за
движением — за жестикуляцией, за проезжающей машиной, за анимацией на экране.
Варианты: поставь OpenCV (`pip install opencv-python`), возьми `--reframe static`,
или отредактируй `.work/<slug>.sendcmd` вручную и перезапусти рендер.

## Субтитры вылезают за край кадра

Такого быть не должно — перенос строк включён. Если всё же: уменьши кегль
`--sub-scale 0.85` или число слов в строке через `--subs words`. Очень длинное
одиночное слово (термин, ссылка) libass не переносит — правь текст в `.work/*.ass`.

## Не тот шрифт

libass молча подставляет свой, если запрошенного нет в системе:

```bash
fc-list | grep -i montserrat        # Linux / macOS
```

Поставь шрифт в систему или укажи установленный: `--font "DejaVu Sans"`.

## Звук тише или громче остальных роликов

`loudnorm` в один проход даёт разброс около ±1 LUFS — для площадок этого хватает.
Если нужна точность, прогони готовый клип вторым проходом или отключи нормализацию
(`--loudness off`) и сведи звук отдельно.

## Трекинг просят, а получается static

Смотри `reframe` в `clips.json`. Причины две: субъект почти не двигался (кейфреймы
схлопнулись в один — это правильное поведение) или ffmpeg собран без `sendcmd`
(в логе будет строка «трекинг не отработал»). Второе лечится другой сборкой ffmpeg.

## Рендер идёт слишком долго

`--preset ultrafast --crf 30` для проверки, потом финальный проход. И всегда
проверяй первый клип через `--only clip-01`, прежде чем ставить пачку из восьми.
