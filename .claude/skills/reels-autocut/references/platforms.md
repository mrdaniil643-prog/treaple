# Параметры под площадки

Цифры — то, что площадки принимают без перекодирования на своей стороне.
Всё остальное они пережмут сами, и обычно хуже.

| Площадка | Формат | Кадр | Длина | Громкость |
|---|---|---|---|---|
| Instagram Reels | 9:16 | 1080×1920 | 15–90 с | −14 LUFS |
| Instagram лента | 4:5 | 1080×1350 | до 60 с | −14 LUFS |
| TikTok | 9:16 | 1080×1920 | 21–60 с (лучше до 34) | −14 LUFS |
| YouTube Shorts | 9:16 | 1080×1920 | до 60 с | −14 LUFS |
| VK Клипы | 9:16 | 1080×1920 | 15–60 с | −14 LUFS |
| Telegram | 9:16 или 16:9 | 1080×1920 | без жёсткого лимита | −16 LUFS |

Команды:

```bash
# Reels / Shorts / TikTok
--ratio 9:16 --max-height 1920 --loudness -14

# Лента Instagram
--ratio 4:5 --loudness -14

# Telegram / архив
--ratio source --subs plain --loudness -16
```

## Безопасные зоны

Интерфейс плеера перекрывает края вертикального кадра:

- снизу ~15–20% — подпись, звук, кнопки;
- справа ~12% — лайки и шеры;
- сверху ~10% — аватар и название.

Значение по умолчанию `--sub-margin 0.18` ставит субтитры прямо над нижней панелью.
Если площадка рисует больше (TikTok с длинной подписью) — `--sub-margin 0.26`.

## Длина

Короткие клипы досматривают до конца, а это главный сигнал для алгоритма. Практика:

- 15–25 с — одна мысль, один вывод. Самый высокий процент досмотров.
- 25–40 с — мысль с примером. Рабочий диапазон по умолчанию (`--sweet 32`).
- 40–60 с — только если внутри есть развитие и вторая точка удержания.
- Больше 60 с — режь на две части.

## Кодек

По умолчанию H.264 High, yuv420p, `+faststart`, AAC 192k стерео 48 кГц — это
принимают все перечисленные площадки. HEVC и 10-битное видео лучше не отдавать:
часть площадок перекодирует их с заметной потерей.
