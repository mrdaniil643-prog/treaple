# Подбор параметров под материал

## Быстрая настройка

`analyze` дешёвый — прогони его три раза с разными порогами и выбери:

```bash
for n in -45 -35 -25; do
  echo "noise $n"
  python3 jumpcut.py analyze lecture.mp4 --noise $n --max-silence 0.3 2>/dev/null \
    | python3 -c "import json,sys;d=json.load(sys.stdin);print(' ', d['removed_percent'],'%', d['segments'],'отрезков')"
done
```

Ориентир по проценту:

- меньше 10% — порог слишком строгий или запись и правда плотная;
- 20–40% — нормальная лекция или подкаст;
- больше 55% — скорее всего срезает речь: проверь на слух, опусти `--noise`.

Количество отрезков тоже говорит: сотни отрезков на 20 минут — режет внутри слов,
подними `--min-silence` до `0.5`.

## Типовые пресеты

```bash
# Лекция, запись с петличкой, чистый звук
--noise -40 --min-silence 0.4 --max-silence 0.35 --padding 0.08

# Подкаст на двоих, комнатный шум
--noise -32 --min-silence 0.35 --max-silence 0.30 --padding 0.06

# Скринкаст с закадровым голосом, нужна плотность
--noise -38 --min-silence 0.25 --max-silence 0.12 --padding 0.04

# Запись с телефона, шумно
--noise -26 --min-silence 0.5 --max-silence 0.35 --padding 0.10

# Интервью: беречь дыхание и естественность
--noise -38 --min-silence 0.6 --max-silence 0.45 --padding 0.12
```

## Когда silencedetect врёт

- **Кондиционер, вентилятор, улица.** Постоянный фон выше порога — пауз «нет».
  Прогони исходник через шумодав (`afftdn`, Audacity, Adobe Enhance) и уплотняй уже его.
- **Дыхание и причмокивание** громче порога и считаются речью. Это скорее хорошо:
  вырезанное дыхание звучит неестественно.
- **Разная громкость двух спикеров.** Тихого будут резать, громкого нет.
  Сначала нормализуй: `ffmpeg -i in.mp4 -af loudnorm=I=-16:TP=-1.5:LRA=11 -c:v copy norm.mp4`.

## Что даёт какой выигрыш

На часовой разговорной записи, типично:

| Что | Сколько уходит |
|---|---|
| Паузы при `--max-silence 0.3` | 15–30% |
| Паузы при `--max-silence 0.1` | 25–40% |
| Слова-паразиты (осторожный список) | 2–6% |
| Слова-паразиты (расширенный список) | 5–12% |

Паразиты дают меньше минут, но заметно больше по ощущению: речь перестаёт
спотыкаться. Паузы дают минуты.

## Порядок операций

Правильный:

```
исходник → шумодав → нормализация громкости → jumpcut → reels-autocut → музыка
```

Почему так: шумодав и нормализация меняют уровень, а от уровня зависит детекция
пауз. Нарезка на клипы идёт после уплотнения, иначе клипы наберут в себя тишину.
Музыка кладётся последней — её непрерывность рвётся на любом хардкате.
