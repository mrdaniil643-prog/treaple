# Уплотнение речи: паузы и паразиты

Скрипт: `scripts/jumpcut.py`. Два независимых механизма:

1. **Паузы** — ищутся по звуку (`silencedetect`), распознавание не нужно.
   Работает на любом языке и на любом исходнике со звуком.
2. **Слова-паразиты** — по транскрипту со словными таймкодами. Опционально.

Картинка и звук режутся одинаково, поэтому синхрон не разъезжается.

## Быстрый старт

```bash
cd .claude/skills/jumpcut/scripts

# Сначала посмотреть, сколько уйдёт — рендера не будет
python3 jumpcut.py analyze lecture.mp4 --max-silence 0.30

# Если цифра устраивает
python3 jumpcut.py run lecture.mp4 --out lecture-tight.mp4 --max-silence 0.30
```

`analyze` занимает примерно столько же, сколько чтение звука (минуты на час записи),
и ничего не пишет. **Всегда прогоняй его первым и покажи цифру пользователю.**
«Убрали 41% длительности» — это решение, а не деталь реализации.

## Как работает вырезание пауз

Пауза не удаляется целиком — из её середины вырезается кусок так, чтобы осталось
примерно `--max-silence` секунд. Края (`--padding`) не трогаются: без них срезается
атака следующего слова и стык слышно.

```
было:  …слово [========= 3.2 с тишины =========] слово…
стало: …слово [0.3 с] слово…
```

| Ключ | Что делает | По умолчанию |
|---|---|---|
| `--noise` | порог тишины в dB; ниже — строже | `-35` |
| `--min-silence` | короче этого паузой не считается | `0.35` |
| `--max-silence` | сколько тишины оставить вместо длинной; `0` — вырезать под ноль | `0.30` |
| `--padding` | неприкосновенные края паузы | `0.06` |
| `--min-keep` | выбросить обрывки короче этого | `0.12` |

**Подбор `--noise`.** Если вырезалось слишком мало — шумный фон, тишина не опознаётся:
подними порог до `-30` или `-25`. Если срезает начала слов — опусти до `-40`, `-45`.
Ориентир: чистая студийная запись `-40`, запись с ноутбука `-35`, шумная комната `-28`.

**Подбор `--max-silence`.** `0.30` — разговорный темп, дыхание сохраняется.
`0.15` — плотно, для коротких роликов. `0` — жёстко, речь идёт встык; годится для
скринкастов, но в интервью звучит неестественно.

## Слова-паразиты

```bash
# 1. Транскрипт со словными таймкодами (соседний навык)
python3 ../../reels-autocut/scripts/autocut.py transcribe lecture.mp4 \
        --out lecture.transcript.json --lang ru

# 2. Вырезать паразиты вместе с паузами
python3 jumpcut.py run lecture.mp4 --out tight.mp4 \
        --transcript lecture.transcript.json --fillers
```

Список по умолчанию осторожный: `эээ`, `ммм`, `короче`, `типа`, `как бы`, `ну вот`,
`это самое`, `um`, `uh`, `you know`, `i mean` и подобные — то, что почти никогда
не несёт смысла.

Спорные слова (`значит`, `в общем`, `то есть`, `like`, `actually`, `basically`)
в список **не входят**: они часто осмысленные, и их вырезание ломает фразу.
Нужны — передай свой список:

```bash
python3 -c "import json;json.dump(['эээ','короче','значит'],open('f.json','w'),ensure_ascii=False)"
python3 jumpcut.py run lecture.mp4 --out tight.mp4 \
        --transcript t.json --fillers --fillers-file f.json
```

Вырезание паразитов бьёт по слуху заметнее, чем вырезание пауз: слово убирается из
середины фразы. Прослушай результат, прежде чем отдавать.

## Если дальше идёт нарезка на рилсы

Транскрипт после уплотнения разъезжается — таймкоды старые. Пересчитай их:

```bash
python3 jumpcut.py run lecture.mp4 --out tight.mp4 \
        --transcript lecture.transcript.json --fillers \
        --shift-transcript tight.transcript.json

python3 ../../reels-autocut/scripts/autocut.py plan \
        --transcript tight.transcript.json --source tight.mp4 --out plan.json
```

`--shift-transcript` переносит слова на новый таймлайн и выбрасывает те, что попали
в вырезанные куски. Без этого субтитры в клипах уедут.

## Раздельные шаги

```bash
python3 jumpcut.py plan lecture.mp4 --out cut-plan.json --max-silence 0.2
# поправить "keep" в cut-plan.json руками
python3 jumpcut.py render --plan cut-plan.json --out tight.mp4 --crf 18 --preset slow
```

В `cut-plan.json` лежит `keep` — список отрезков `{start, end}`, которые попадут
в результат. Его можно править: выкинуть кусок целиком, вернуть паузу перед важной
фразой, склеить соседние отрезки.

## Что помнить

- **Это перекодирование, а не копирование потока.** Час видео — минуты рендера.
  Для черновика `--crf 30 --preset ultrafast`, для финала `--crf 18 --preset slow`.
- **Хардкат режет и картинку.** Если спикер в кадре, на стыках он будет «прыгать» —
  это и есть jump cut, так и задумано. Если прыжки мешают, поставь `--max-silence`
  побольше: реже стыки — спокойнее картинка.
- **Микрофейды звука** (`--fade 0.012`) стоят по умолчанию, иначе на стыках щёлкает.
  `--fade 0` отключает, если нужен абсолютно точный тайминг.
- **Музыка и фоновый звук ломаются.** Скрипт режет общую дорожку; непрерывный
  музыкальный фон на стыках будет дёргаться. Уплотняй до подкладывания музыки.
- **Проверь результат на слух**, прежде чем отдавать. Особенно с `--fillers`.
