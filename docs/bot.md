# Бот: кинул видео — получил нарезку

Один бот в Telegram. Отправляете ему ссылку — через полчаса приходят
готовые вертикальные клипы с субтитрами.

## Почему это две части, а не одна

Боту нужен процесс, который слушает круглосуточно. Нарезке нужен
процессор на полчаса. Это разные задачи, и совмещать их в одном месте
нечем: держать постоянный слушатель внутри GitHub Actions прямо
запрещено правилами использования, и за это блокируют аккаунт.

Поэтому:

```
Telegram ──▶ Cloudflare Worker ──▶ GitHub Actions ──▶ Telegram
             всегда онлайн,        нарезает,           клипы
             отвечает мгновенно    бесплатно           и статусы
```

Обе части бесплатны без карты и без лимита по времени. Для вас это один
бот: пишете ему, он отвечает.

## Настройка

Всё делается в Safari на телефоне. Минут тридцать.

### 1. Бот и токен

[@BotFather](https://t.me/BotFather) → `/newbot` → имя и username.
Сохраните токен вида `1234567890:AA...`.

### 2. Свой chat_id — обязательно до шага 5

Напишите боту «привет», затем откройте в Safari:

```
https://api.telegram.org/bot<ТОКЕН>/getUpdates
```

Найдите `"chat":{"id":123456789` — это ваш chat_id.

**Порядок важен.** Как только на шаге 5 включится вебхук, `getUpdates`
перестанет отдавать сообщения. Узнайте id сейчас.

### 3. Токен GitHub

GitHub → Settings → Developer settings → Personal access tokens →
**Fine-grained tokens** → Generate new token.

- Repository access: только `treaple`
- Permissions → Repository permissions → **Contents: Read and write**

Сохраните токен.

### 4. Worker в Cloudflare

Регистрация на [dash.cloudflare.com](https://dash.cloudflare.com) —
бесплатно, карта не нужна.

1. **Compute (Workers)** → **Create** → **Start from Hello World** →
   имя, например `clipper-bot` → **Deploy**.
2. **Edit code** → удалить всё, вставить содержимое
   [`bot/worker.js`](../bot/worker.js) → **Deploy**.
3. **Settings** → **Variables and Secrets** → добавить пять штук
   (тип **Secret**):

| Имя | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен из шага 1 |
| `WEBHOOK_SECRET` | любая случайная строка, придумайте сами |
| `GITHUB_TOKEN` | токен из шага 3 |
| `GITHUB_REPO` | `mrdaniil643-prog/treaple` |
| `ALLOWED_CHAT_IDS` | ваш chat_id из шага 2 |

`ALLOWED_CHAT_IDS` — не формальность: без него любой, кто найдёт бота,
сможет запускать прогоны от вашего имени.

Адрес воркера — вида `https://clipper-bot.ваш-логин.workers.dev`.

### 5. Включить вебхук

Откройте в Safari, подставив свои значения:

```
https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=<АДРЕС_ВОРКЕРА>&secret_token=<WEBHOOK_SECRET>
```

Ответ `{"ok":true,...}` — значит, готово.

### 6. Секреты в GitHub

Репозиторий → Settings → Secrets and variables → Actions:

| Имя | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | тот же токен |
| `TELEGRAM_CHAT_ID` | ваш chat_id (запасной адрес для ручных запусков) |

### 7. Перенести воркфлоу в основную ветку

`repository_dispatch` всегда запускает воркфлоу **из ветки по
умолчанию**. Сейчас код в `claude/telegram-development-ideas-gao9b9`, а
по умолчанию стоит другая ветка — бот будет получать от GitHub ошибку.

Слейте Pull request или переключите ветку по умолчанию в
Settings → General.

## Как пользоваться

Просто отправьте боту ссылку:

```
https://youtu.be/abc123
```

Настройки — словами в том же сообщении, в любом порядке:

```
https://youtu.be/abc123 8 ru medium blur
```

| Слово | Что делает |
|---|---|
| число | сколько клипов (1–20) |
| `ru` `en` `uk` … | язык распознавания |
| `tiny` `small` `medium` `large-v3` | модель: точность против скорости |
| `smart` `center` `blur` | как кадрировать под вертикаль |

Слова внутри ссылки не читаются как настройки, так что за адрес можно не
переживать.

Видео файлом тоже принимается, но Telegram отдаёт ботам максимум 20 МБ —
это пара минут записи. Длинное выкладывайте куда-нибудь и присылайте
ссылку.

## Что стоит знать

**Сколько ждать.** Часовой подкаст на модели `small`: около получаса.
Бот пишет, когда взялся, и присылает клипы по мере готовности.

**Если упало** — бот напишет об этом и даст ссылку на лог. Молчания не
будет.

**YouTube и серверные адреса.** Раннеры GitHub сидят на IP дата-центров,
и YouTube с них заметно чаще требует подтверждение «я не робот».
Скачивание может не пройти. Лечится секретом `YOUTUBE_COOKIES` в GitHub
(содержимое cookies.txt в формате Netscape от залогиненного аккаунта).

**Клипы по 50 МБ.** Больше бот отправить не может — это лимит Telegram.
Слишком тяжёлый клип пережимается автоматически.

**Сколько это стоит.** Ноль. Cloudflare Workers — 100 000 запросов в
сутки бесплатно, Actions на публичном репозитории не лимитированы.

## Проверить, что вебхук жив

```
https://api.telegram.org/bot<ТОКЕН>/getWebhookInfo
```

Смотрите на `last_error_message`. Пусто — всё в порядке. Если там 403,
не совпадает `WEBHOOK_SECRET` между Cloudflare и вызовом `setWebhook`.
