# Нарезка клипов с iPhone, без компьютера

Тяжёлые этапы (распознавание речи и кодирование видео) упираются в
процессор, и на iPhone их не запустить. Поэтому считает чужая машина —
бесплатный раннер GitHub Actions, — а телефон только отдаёт команду и
принимает результат.

```
iPhone  ──ссылка──▶  GitHub Actions  ──готовые клипы──▶  Telegram  ──▶  iPhone
 (пульт)              (бесплатно,                        (доставка)     (заливка
                       безлимитно на                                     в Shorts
                       публичном репо)                                   и Reels)
```

Настройка занимает минут двадцать и делается целиком в Safari на телефоне.

---

## Шаг 1. Бот в Telegram

1. Откройте [@BotFather](https://t.me/BotFather), команда `/newbot`.
2. Придумайте имя и username (должен заканчиваться на `bot`).
3. BotFather пришлёт токен вида `1234567890:AA...`. **Скопируйте его.**

## Шаг 2. Свой chat_id

1. Напишите своему новому боту любое сообщение — хоть «привет».
   Без этого бот не имеет права вам писать.
2. Откройте в Safari, подставив токен:
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
3. Найдите в ответе `"chat":{"id":123456789` — это ваш chat_id.

## Шаг 3. Секреты в GitHub

В Safari: репозиторий → **Settings** → **Secrets and variables** →
**Actions** → **New repository secret**. Добавьте два:

| Имя | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен из шага 1 |
| `TELEGRAM_CHAT_ID` | число из шага 2 |

Секреты зашифрованы и не видны в логах даже на публичном репозитории.

## Шаг 4. Перенести воркфлоу в основную ветку

**Это обязательно.** Кнопка «Run workflow» и запуск по API работают только
для воркфлоу, лежащего в ветке по умолчанию. Сейчас файл в ветке
`claude/telegram-development-ideas-gao9b9`.

Откройте Pull request из этой ветки и слейте его — или в
**Settings → General → Default branch** переключите ветку по умолчанию на
неё.

---

## Запуск: способ 1 — кнопка

Репозиторий → **Actions** → слева **Clip** → **Run workflow**.

Поля: ссылка на видео, сколько клипов, язык (`ru`), модель, режим
кадрирования. Нажали — минут через двадцать-тридцать клипы придут в
Telegram.

## Запуск: способ 2 — шеринг из YouTube в одно касание

Удобнее: смотрите подкаст, жмёте «Поделиться» → ваша команда → всё.

**Токен доступа.** GitHub → Settings → Developer settings →
Personal access tokens → **Fine-grained tokens** → Generate new token.
Доступ — только к репозиторию `treaple`, права: **Contents → Read and
write**. Скопируйте токен.

**Команда в приложении «Быстрые команды»:**

1. Новая команда → в настройках включите **Показывать в меню «Поделиться»**,
   тип входных данных — URL.
2. Действие **Получить содержимое URL-адреса**:
   - Адрес: `https://api.github.com/repos/mrdaniil643-prog/treaple/dispatches`
   - Метод: **POST**
   - Заголовки:
     - `Authorization` → `Bearer ВАШ_ТОКЕН`
     - `Accept` → `application/vnd.github+json`
     - `X-GitHub-Api-Version` → `2022-11-28`
   - Тело запроса: **JSON**
     - `event_type` (текст) → `clip`
     - `client_payload` (словарь):
       - `url` (текст) → переменная **Вход быстрой команды**
       - `count` (текст) → `6`
       - `language` (текст) → `ru`
3. Действие **Показать уведомление** → «Отправлено в нарезку».

Теперь в YouTube: «Поделиться» → ваша команда. Через полчаса клипы в чате.

## Дальше: публикация с телефона

Клипы приходят в Telegram готовыми: 1080×1920, с вшитыми субтитрами, со
звуком, нормализованным под −14 LUFS. Сохраняете в «Фото» и заливаете
как обычно — YouTube и Instagram на iPhone принимают вертикальные видео
без дополнительной обработки. Заголовок и хештеги идут подписью к видео,
их можно скопировать прямо из чата.

## Что стоит знать заранее

**YouTube и IP дата-центров.** Раннеры GitHub сидят на серверных адресах,
и YouTube заметно чаще требует с них подтверждение «я не робот».
Скачивание может не пройти. Лечится файлом cookies от залогиненного
аккаунта: положите его содержимое в секрет `YOUTUBE_COOKIES` (формат
Netscape), воркфлоу подхватит автоматически. Экспортировать cookies с
iPhone неудобно, так что рассчитывайте на осечки и имейте в виду
источники помимо YouTube.

**Лимит Telegram — 50 МБ на файл от бота.** Клип на 30–60 секунд обычно
весит 5–20 МБ, так что запас есть. Если файл всё же перевалит за лимит,
код автоматически пережмёт его сильнее и отправит.

**Сколько идёт прогон.** Часовой подкаст на модели `small`: скачивание
1–3 минуты, распознавание 15–25, рендер шести клипов 3–6. Итого
полчаса. Минуты на публичном репозитории бесплатны и не лимитированы,
так что гонять можно сколько угодно.

**Артефакты публичны.** На публичном репозитории файлы, приложенные к
прогону, может скачать кто угодно. Поэтому галка «Also attach clips»
выключена по умолчанию — доставка идёт в Telegram, а он приватный.

**Модель побольше.** Если распознавание русского ошибается на именах и
терминах, поставьте `medium` вместо `small`: точнее, но прогон вырастет
примерно вдвое. Минуты бесплатные, так что это ничего не стоит, кроме
ожидания.
