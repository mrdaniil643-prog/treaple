# Сайт юриста Ярослава Сазикова

Статический сайт: HTML, CSS и ванильный JavaScript без сборки. Заявки уходят в Telegram
через одну serverless-функцию. Внешних зависимостей нет, шрифты лежат рядом с сайтом.

---

## Сначала прочитайте это

На сайте нет выдуманных фактов. Отзывы, регалии, реестровый номер, ИНН, стаж,
адрес, почта, часы работы, город и цены убраны: их никто не подтверждал. Осталось
то, что дал заказчик, и то, что описывает работу без проверяемых утверждений.

| Что на сайте | Откуда | Что сделать |
|---|---|---|
| Имя «Ярослав Сазиков», телефон `+7 909 854-88-61` | дал заказчик | ничего |
| «Юрист по гражданским делам» | исходный бриф | подтвердить специализацию |
| «Первая консультация бесплатная» | предложение лендинга | подтвердить, что это так |
| Фраза о подходе в блоке заявки и тексты ситуаций | написаны от его лица | дать ему прочитать |
| Ответы в разделе «Частые вопросы» | общие нормы ГК и ГПК | дать ему проверить формулировки |
| `privacy.html`, `consent.html` | составлены по тому, что делает сайт | проверить и утвердить как оператор |

### Персональные данные: что сделано и что остаётся оператору

Сделано на сайте:

- Политика обработки ПДн (`privacy.html`) и отдельный текст согласия (`consent.html`).
  Оба описывают ровно то, что делает код: какие поля уходят, куда, зачем и как долго.
- В обеих формах флажок согласия, без него заявка не уходит ни в браузере, ни на сервере.
- Значение флажка — дата редакции согласия. Сервер принимает только текущую редакцию
  и пишет её в каждую заявку: «Согласие на обработку ПДн: дано, редакция от …».
  Это доказательство согласия, которое по ч. 3 ст. 9 152-ФЗ лежит на операторе.
- Сайт не ставит cookie и не подключает аналитику.

Остаётся оператору, кодом это не решить:

1. **Утвердить документы.** Ярослав юрист и оператор: тексты должен прочитать он.
   Срок хранения заявок 30 дней выбран по умолчанию, поправьте, если нужен другой.
2. **Добавить адрес для письменных запросов.** Сейчас для обращений по ПДн указан
   только телефон. Почта или почтовый адрес нужны, чтобы человек мог направить запрос
   письменно.
3. **Подать уведомление в Роскомнадзор** об обработке персональных данных и о
   трансграничной передаче: заявки уходят через Telegram, его серверы за границей.
4. **Решить вопрос локализации.** Закон требует, чтобы запись и хранение ПДн граждан
   России шли в базах на территории России (ч. 5 ст. 18 152-ФЗ). Если чат в Telegram
   становится единственным местом, где копятся заявки, это требование не выполнено.
   Вариант: основная копия в российском сервисе (почта или CRM с серверами в России),
   Telegram только для уведомлений. Это меняет функцию и документы, решать заказчику.

При изменении текста согласия поменяйте дату в `CONSENT_REVISION` (`api/lead.js`),
в значениях флажков (`index.html`) и в строках «Редакция от …» обоих документов.
Тест `tests/consent.test.mjs` проверит, что всё сошлось.

## Локальный запуск

```bash
npm run dev          # python3 -m http.server 4173
# открыть http://127.0.0.1:4173
```

Форма при этом будет ругаться на отсутствующий `/api/lead`. Откройте
`http://127.0.0.1:4173/?demo=1`, чтобы посмотреть на успешную отправку без бэкенда,
или запустите `vercel dev` для проверки настоящей доставки в Telegram.

## Заявки в Telegram

1. Напишите [@BotFather](https://t.me/BotFather), команда `/newbot`. Получите токен
   вида `123456789:AA...`.
2. Создайте чат или группу, куда будут падать заявки, и добавьте туда бота.
3. Отправьте боту любое сообщение, затем откройте
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и возьмите
   `result[0].message.chat.id`. У групп id отрицательный.
4. Задайте переменные окружения на хостинге:

```
TG_BOT_TOKEN=123456789:AA...
TG_CHAT_ID=-1001234567890
```

Токен читает только серверная функция. В браузер он не попадает, в репозиторий тоже:
`.env` лежит в `.gitignore`.

Других получателей у заявки нет. Если понадобится копия на почту, подключайте
российского провайдера и сначала допишите его в `privacy.html` и `consent.html`.

### Что уже сделано против спама и сбоев

- Скрытое поле-ловушка `company`: люди его не видят, боты заполняют. Такие заявки
  отбрасываются с ответом 200, чтобы спамер не подбирал обход.
- Не больше 3 заявок в минуту с одного IP. Адрес берётся из `x-real-ip`, затем из
  `x-forwarded-for`: Vercel перезаписывает оба, подделать их снаружи нельзя. На другом
  хостинге проверьте, какой заголовок ставит ваш прокси.
- Сервер проверяет имя и все 11 цифр телефона, а не полагается на браузер.
- Тело запроса, которое не является JSON-объектом, получает 400.
- Управляющие символы вырезаются, `& < > "` экранируются перед отправкой в Telegram.
- Запрос в Telegram ограничен 6 секундами: если Telegram завис, человек получает
  ошибку с номером телефона, а не бесконечное ожидание.
- Заявка без согласия текущей редакции получает 400.

Счётчик лимита живёт в памяти инстанса функции и вычищает устаревшие адреса сам.
Для сайта одного юриста этого хватает. Под нагрузкой замените на Upstash Redis
или Vercel KV.

## Публикация

### Vercel (рекомендую, функция работает из коробки)

```bash
npm i -g vercel
vercel                      # первый деплой
vercel env add TG_BOT_TOKEN
vercel env add TG_CHAT_ID
vercel --prod
```

### Netlify

Перенесите `api/lead.js` в `netlify/functions/lead.js` и замените экспорт:

```js
export default async (req) => { /* тело функции */ }
```

В `netlify.toml` добавьте редирект `/api/lead` → `/.netlify/functions/lead`.

### GitHub Pages

Репозиторий публичный, поэтому Pages бесплатны. Папка называется `docs`, потому что
Pages умеет отдавать статику только из корня репозитория или из `docs/`.

Settings → Pages → Build and deployment → Source: **Deploy from a branch** →
ветка `claude/legal-site-animations-aj7zu1`, папка **/docs** → Save.
Через минуту сайт поднимется на `https://mrdaniil643-prog.github.io/treaple/`.

Файл `.nojekyll` рядом с `index.html` отключает Jekyll: без него Pages может
не отдать часть файлов из `assets`.

Serverless-функции на Pages нет, поэтому форма там работает в режиме превью
(см. ниже). Для приёма заявок нужен хостинг с функциями.

### Обычный хостинг без Node

Статику кладите как есть. Для формы поднимите функцию отдельно (Vercel, Cloud
Functions, любой PHP-скрипт с тем же контрактом) и пропишите адрес до загрузки
`main.js`:

```html
<script>window.LEAD_ENDPOINT = 'https://api.example.ru/lead'</script>
```

Ответ должен быть `200` с JSON-телом, иначе на сайте покажется ошибка.

Если сайт при этом лежит на Vercel, CSP из `vercel.json` заблокирует и встроенный
скрипт, и запрос на чужой адрес. Добавьте адрес функции в `connect-src` в
`tests/csp.test.mjs` и выполните `npm run csp:update`.

### Режим превью формы

Там, где бэкенда нет, форма проходит валидацию и показывает успех, но заявку
никуда не отправляет. Режим включается тремя способами:

- домен оканчивается на `github.io`;
- в адресе есть `?demo=1`;
- до загрузки `main.js` задано `window.LEAD_ENDPOINT = 'demo'`.

На собственном домене клиента ни одно из условий не срабатывает, так что боевая
форма всегда идёт на реальный эндпоинт. Логика лежит в `main.js`, функция
`sendLead`. Если режим не нужен вовсе, удалите переменную `DEMO` и вызывайте
`fetch` напрямую.

## Как менять внешний вид

Вся тема собрана в блоке `:root` в начале `styles.css`. Цвета, шрифты, отступы,
скругления и тайминги анимаций лежат переменными. Хардкод-цветов в компонентах нет,
поэтому смена палитры — это правка десяти строк.

```css
--paper:#F1F2EF;   /* фон страницы */
--paper-2:#FFFFFF; /* карточки и панели форм */
--band:#E7E9E3;    /* чередующиеся полосы секций */
--ink:#15202E;     /* заголовки и основной текст */
--seal:#7B2C31;    /* единственный акцент: линии, цифры, главная кнопка */
--seal-on-ink:#C98A8F; /* тот же акцент на тёмном футере */
--font-display:'EB Garamond', …   /* заголовки */
--font-text:'Manrope', …          /* текст */
```

Тема светлая: бумага, чернила и один акцент цвета сургучной печати. Поверхности
различаются светлотой, а не рамками и тенями. Тени не используются нигде.
Все три уровня текста (`--ink`, `--ink-2`, `--ink-3`) проходят WCAG AA и на бумаге,
и на полосе: это проверяет автотест. Если добавляете блок, берите готовую переменную,
а не новый цвет.

Тёмный здесь только футер. Это намеренная инверсия, которая закрывает лист снизу.

### Шрифты

EB Garamond для заголовков и Manrope для текста лежат в `assets/fonts` подмножествами
cyrillic и latin, вместе 107 КБ. Оба вариативные, вес 400–700. Внешних запросов к
Google Fonts нет, поэтому сайт не зависит от их доступности.

## Доступность и мобильная версия

- Переходы 300–450 мс, `cubic-bezier(.22,1,.36,1)`. Анимируются только `transform`
  и `opacity`.
- Заголовок первого экрана выезжает CSS-анимацией и не ждёт `main.js`.
- `prefers-reduced-motion: reduce` отключает анимации.
- Без JavaScript страница читается полностью, вопросы раскрываются штатным `<details>`.
  Если `main.js` не загрузился, через 3 секунды скрипт в `<head>` снимает класс `js`.
- Фокус виден на всех интерактивных элементах, тач-цели от 44 px.
- На телефоне внизу экрана панель «Позвонить» и «Оставить заявку». Она появляется
  после первого экрана и прячется, когда на экране форма заявки.
- Ссылки на документы из форм открываются в новой вкладке: набранный текст не теряется.
- Короткие предлоги связаны со следующим словом неразрывным пробелом.

Lighthouse, мобильный профиль, сервер со сжатием как на Vercel: производительность
99–100, доступность 100, практики 100, SEO 100; LCP 1,7 с, CLS 0.

## Безопасность

`vercel.json` отдаёт Content-Security-Policy: скрипты и стили только с сайта, плюс
встроенные блоки по хешу. Правите встроенный `<script>` или `<style>` в любой
странице — выполните `npm run csp:update`, иначе браузер его заблокирует.
`npm test` упадёт, если хеши разошлись.

## О текстах

Тексты написаны по правилам скилла `stop-slop`: без риторических вопросов в
заголовках, без конструкций «не X, а Y», без обрывочных фраз ради эффекта и без
наречий-усилителей. Если будете дописывать разделы, держите тот же тон: активный
залог, конкретика вместо оценок, первое лицо и обращение на «вы». Не добавляйте
фактов, которые Ярослав не подтвердил: рядом с настоящим именем они читаются как
проверенные.

## Команды

```bash
npm run dev          # локальный сервер на 4173
npm run check        # синтаксис main.js и api/lead.js
npm test             # функция заявок, CSP, редакция согласия (без сети)
npm run test:e2e     # страница в браузере, нужен запущенный dev и Playwright
npm run csp:update   # пересчитать хеши CSP после правки встроенного кода
npm run images       # пересобрать og.png и apple-touch-icon.png
```

Для `test:e2e` и `images`: `pip install playwright && playwright install chromium`.

`tests/api.test.mjs` подменяет `fetch` и проверяет доставку в Telegram, экранирование
HTML, отказ на пустое тело, ловушку для ботов, согласие и его редакцию, неполный номер,
таймаут Telegram и лимит в 3 заявки в минуту.

`tests/e2e.py` проверяет три ширины экрана на горизонтальный скролл и ошибки в
консоли; маску телефона, в том числе набор с 8; валидацию и флажок согласия в обеих
формах; документы; CSP в браузере; раскрытие вопросов; отступ под шапкой; панели
вызова; контраст; reduced-motion; отказ `main.js` и работу без JavaScript.
