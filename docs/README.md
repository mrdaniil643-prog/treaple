# Сайт-визитка адвоката Ярослава Сазикова

Одна страница: портрет, имя, специализация, телефон и четыре коротких пункта о том,
с чем он помогает. HTML и CSS без JavaScript, без сервера, без форм. Шрифты и фото
лежат рядом со страницей, внешних запросов нет.

## Реклама адвоката: чего на сайте быть не может

Статья 17 Кодекса профессиональной этики адвоката разрешает информацию об адвокате,
если в ней нет оценочных характеристик («опытный», «лучший»), отзывов, сравнений
с другими адвокатами и обещаний результата («гарантирую оправдание»). Сейчас ничего
из этого нет. Добавлять можно реестровый номер и адвокатское образование: клиент
проверит статус в реестре.

## Публикация

Сайт статический, подойдёт любой хостинг.

**GitHub Pages.** Settings → Pages → Source: *Deploy from a branch* →
ветка `claude/legal-site-animations-aj7zu1`, папка `/docs` → Save.
Адрес: `https://mrdaniil643-prog.github.io/treaple/`.

**Vercel.** `npm i -g vercel`, затем `vercel --prod` из папки `docs`. На Vercel
действуют заголовки из `vercel.json`: кеш шрифтов и картинок и Content-Security-Policy.
README, тесты и инструменты в выкладку не попадают (`.vercelignore`).

**Свой домен.** После подключения домена впишите полный адрес в `og:image`
(`https://ваш-домен/assets/img/og.jpg`) и добавьте `og:url`: Facebook и часть парсеров
не понимают относительный путь. Telegram обычно справляется и так.

## Как менять

**Текст** — прямо в `index.html`. После правки свяжите короткие предлоги со следующим
словом: `python3 tools/nbsp.py index.html`.

**Цвета и шрифты** — блок `:root` в начале `styles.css`. Единственный акцент —
`--seal:#7B2C31`, цвет сургучной печати. Все уровни текста проходят WCAG AA.

**Портрет.** Положите новые файлы с теми же именами: `portrait-480/720/960.webp`
и `portrait-720.jpg` в пропорции 3:4, `portrait-wide-480/720.webp` и
`portrait-wide-720.jpg` в пропорции 4:3 для экранов уже 860 px. Затем
`npm run images`, чтобы обновить превью ссылки.

**Встроенный код.** На главной встроенного кода нет. В `404.html` есть встроенный
скрипт и стиль: правите их — выполните `npm run csp:update`, иначе браузер на Vercel
их заблокирует. `npm test` упадёт, если хеши разошлись.

## Проверки

```bash
npm run dev          # локальный сервер на 4173
npm test             # хеши CSP совпадают с встроенным кодом
npm run test:e2e     # страница в браузере (нужен Playwright)
```

`tests/e2e.py` проверяет на трёх ширинах экрана: нет горизонтального скролла и ошибок,
кнопка звонка помещается в первый экран и ведёт на верный номер, портрет загрузился
нужным кадром в WebP. Ещё проверяет контраст текста, reduced-motion, CSP в браузере
и вид без JavaScript.

Lighthouse на сервере со сжатием как на Vercel. Телефон: производительность 99,
доступность, практики и SEO по 100, LCP 1,8 с. Компьютер: 100 по всем четырём, LCP 0,4 с.
