# Угарный бот для чата друзей

## Что умеет

| Команда | Что делает |
|---|---|
| `/krasavchik` | Выбирает красавчика дня (с драматичной интригой, один раз в сутки) |
| `/klown` | Выбирает клоуна дня |
| `/top` | Зал славы и позора: кто сколько раз был красавчиком или клоуном |
| `/kto <текст>` | «Кто из нас сегодня проставляется?» Бот назовёт одного из чата |
| `/shar <вопрос>` | Магический шар с ответами |
| `/rate <что угодно>` | Оценка от 0 до 10 с комментарием |
| `/iq` | Меряет IQ. Если ответить командой на чужое сообщение, меряет IQ автора |
| `/kogda <событие>` | Называет дату, когда это случится (или «никогда») |
| `/duel` | Ответь на чьё-то сообщение и вызови его на дуэль |
| `/predskazanie` | Личное предсказание на сегодня |

Без команд бот тоже иногда влезает в разговор: отвечает рифмой на «да», «нет», «где», а ещё изредка пишет что-нибудь вроде «Скрин сделан 📸».

## Запуск

1. Напиши [@BotFather](https://t.me/BotFather), создай бота командой `/newbot` и получи токен.
2. **Важно:** в BotFather сделай `/setprivacy`, выбери бота и нажми **Disable**.
   Иначе бот не увидит обычные сообщения и не узнает, кто есть в чате.
3. Добавь бота в группу. Если он уже был там до смены privacy, удали его и добавь заново.
4. Запусти:

```bash
pip install -r requirements.txt
export BOT_TOKEN="токен_от_BotFather"
python bot.py
```

Бот знает только тех, кто хотя бы раз написал в чат после его добавления
(Telegram не даёт ботам список участников).

## Настройка

- Все шутки лежат в `texts.py`. Добавь туда локальные мемы своей компании, так будет смешнее всего.
- `RANDOM_REPLY_CHANCE` задаёт шанс случайного комментария (по умолчанию 2%).
- `RHYME_CHANCE` задаёт шанс рифмы на «да» и «нет» (по умолчанию 35%).
- `DB_PATH` задаёт путь к базе SQLite (по умолчанию `funbot.db`).

## Где держать круглосуточно

Подойдёт любой VPS или бесплатный хостинг вроде Railway или Render (worker-процесс `python bot.py`).
