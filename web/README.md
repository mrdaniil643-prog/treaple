# Веб-версия

Одностраничное приложение без сборки: `index.html` содержит всё — стили,
логику и разметку. Открывается как есть.

## Где оно живёт

Опубликовано как артефакт claude.ai:
<https://claude.ai/artifact/DPb4p6T8FHwGSe5LLGyoWj>

Страница приватная — открывается под вашей учётной записью. На айфоне:
Safari → «Поделиться» → «На экран "Домой"», дальше запускается как обычное
приложение, без адресной строки.

## Хранилище

Товары лежат в хранилище артефакта (`db`) — то есть на сервере, а не в
браузере. Поэтому список синхронизируется между всеми устройствами, где вы
вошли в свою учётную запись. Это ровно то, ради чего в iOS-версии нужен
CloudKit и платный аккаунт разработчика.

Если хранилище недоступно (страница открыта вне claude.ai, отозван доступ),
приложение молча переходит на `localStorage` и продолжает работать — данные
тогда живут только в этом браузере. Текущий режим показан чипом в шапке.

## Отличия от iOS-версии

- **График.** Столбцы одного цвета. В iOS они красились ступенями по рангу —
  это ошибка: цвет должен следовать за сущностью, а не за её местом в
  рейтинге, иначе при смене порядка категории перекрашиваются. Длина столбца
  и так кодирует величину, второй канал избыточен.
- **Янтарный сдвинут** с `#B45309` на `#9A6B00`: прежний был неотличим от
  красного (ΔE 8.6 при нормальном зрении, 5.4 при дейтеранопии).
- **Наценка показана полосой** «закупка / прибыль» — пропорция вместо
  абстрактного процента.
- **Широкий экран** раскладывается в две колонки: список и сводка рядом.

## Своё размещение

Файл статический, никакого сервера не нужно. Чтобы выложить на GitHub Pages:
Settings → Pages → Source: ветка, папка `/web`. Тогда синхронизации между
устройствами не будет — вне claude.ai хранилище артефакта недоступно, и
приложение уйдёт в режим `localStorage`.
